### 1️ State you start with

You are in the entangled state:
$$
|\phi_{00}\rangle = \frac{1}{\sqrt{2}} (|00\rangle + |11\rangle)
$$

This means:

* possible measurement outcomes: **|00⟩ or |11⟩**
* each with **50% probability**

No other outcome is possible.

---

### What happens when you measure

You **do not** measure “the whole thing at once” conceptually — you can think of measuring one qubit first.

#### Case A: first qubit measures to `0`

* The joint state **collapses to |00⟩**
* Therefore:

  * first qubit = 0
  * second qubit = 0

#### Case B: first qubit measures to `1`

* The joint state **collapses to |11⟩**
* Therefore:

  * first qubit = 1
  * second qubit = 1

---

### Key point (this is the essence of entanglement)

> **The second qubit’s value is not chosen independently.**

It is **forced** by the result of the first measurement.

So yes:

> If you get `0` for the first qubit, the second one **must** be `0`.

---

### What you are *not* saying (and this is good)

You are **not** saying:

* the first qubit *caused* the second to be 0
* information traveled between them

You are correctly saying:

* the **joint state already encoded** that rule
