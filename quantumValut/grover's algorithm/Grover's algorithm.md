
a quantum algorithm for so-called _unstructured search_ problems.

#### what is an unstructured search problem?
An **unstructured search problem** is a search task where **there is no exploitable structure or ordering in the search space** that helps you find the target faster than checking possibilities one by one.

given a **set of (N) items**, and you want to find **one item that satisfies a condition**.

* There is **no sorting**
* No hierarchy
* No pattern you can use
* The only thing you can do is **ask questions like**:
  “Does this item satisfy the condition?”

So the search is essentially **blind**.
